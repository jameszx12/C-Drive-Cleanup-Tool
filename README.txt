【目录内容】
  main.py              主程序（GUI + 扫描引擎 + 清理引擎）
  selftest.py          逻辑自测脚本（python selftest.py 运行）
  C盘清理工具.spec     PyInstaller 打包配置
  build.bat            一键打包成 exe 的脚本
  make_icon.py         应用图标生成脚本（python make_icon.py 重新生成 ico）
  app_icon.svg         应用图标源文件（SVG 矢量）
  app_icon.ico         应用图标（多尺寸，打包时嵌入 exe）
  app_icon.png         应用图标预览（256x256）
  C盘清理工具.exe      已打包的可执行文件（可直接运行/复制到桌面）

【如何修改与迭代】
  1. 用任意编辑器（VS Code / 记事本）打开 main.py
  2. 主要可改部分（文件内有中文注释标记）：
       - RULES 字典 / build_rules()：增删清理项与扫描路径
       - APP_NAME / APP_AUTHOR / APP_VERSION：界面标题信息
       - DEEP 扫描的扩展名/目录黑名单：调整“激进”程度
  3. 改完后运行 build.bat 重新打包（需先装好依赖）
  4. 依赖安装（仅需一次）：
       pip install customtkinter pyinstaller

【安全边界说明】
  本工具只清理以下位置的缓存/临时/日志类垃圾：
    - C:\Windows\Temp、SoftwareDistribution、Prefetch 等系统临时目录
    - 各用户 AppData\Local\Temp
    - 可回收站 $Recycle.Bin
    - AppData / ProgramData 下的 cache、temp、logs 类目录
    - 各类 *.log *.tmp *.bak *.dmp *.crdownload 等垃圾扩展名
  绝不触碰：桌面、文档、下载、图片、视频、音乐等个人文件。

【运行说明】
  双击 C盘清理工具.exe 即可。
  因需清理系统目录，程序会请求管理员权限，请点“是”。
  首次运行可能被 Windows SmartScreen 拦截，选择“仍要运行”即可（非病毒）。
